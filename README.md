# 나만의 북마크 포털 (my-portal)

북마크를 **한 화면에 카테고리 → 소그룹 → 링크 순서로 펼쳐 보는** 1장짜리 포털 페이지입니다.
링크 데이터는 이 저장소에 없습니다. **사용자 본인의 비공개 Google Sheets**에만 저장되고,
Apps Script 웹 앱을 통해 읽고 씁니다. 그래서 공용 PC에서도, 다른 기기에서도,
페이지 주소 한 줄만 있으면 로그인한 브라우저 어디서든 같은 화면이 열립니다.

```
브라우저 (이 페이지)  ──JSONP / POST──▶  Apps Script 웹앱  ──▶  비공개 Google Sheets
```

## 화면

- **첫 화면 = 대시보드** — 카테고리 카드 안에 링크가 칩(chip)으로 놓이고,
  카테고리 안에 **소그룹(하위 층위)** 이 있으면 들여쓴 구역으로 묶여 보입니다.
- **📌 즐겨찾기 바** — 핀 고정한 링크를 가장 큰 버튼으로 한 줄에.
- **접기/펼치기** — 카테고리·소그룹 각각 `▾ / ▸`. 접힌 상태는 `localStorage`와 시트 `설정` 탭에 저장.
- **빠른 검색** — `/`로 검색창 포커스, 이름·카테고리·설명으로 실시간 필터, `Enter`로 첫 결과 열기.
- **즉시 표시(SWR)** — `#s=` 연결 주소별로 마지막 화면을 캐시해 **0ms에 먼저 그리고**,
  뒤에서 시트의 최신 내용을 조용히 받아 바뀐 부분만 다시 그립니다.

## 배치 (편집 모드 없이, 첫 화면에서)

- 링크 칩을 **끌어서** 같은/다른 카테고리·**소그룹**으로 이동, 순서 변경 — 놓는 즉시 자동 저장(`saveAll`).
- 카테고리 머리글(⠿)을 끌어 **카테고리 순서 변경**.
- 드래그 중에는 **4px 굵은 삽입선 + 글로우**, 대상 카테고리/소그룹 테두리 하이라이트,
  접힌 구역 위에 머물면 자동으로 펼쳐집니다.
- 터치 기기에서는 **길게 눌러(0.2초) 끌기**, 마우스는 바로 끌기.

## ✏️ 편집 모드 (삭제·수정은 여기서만)

- `✏️ 편집`을 누르는 순간 **현재 상태 전체를 스냅샷**으로 잡습니다.
- 편집 중에는 시트에 쓰지 않고 로컬에서만 바꿉니다.
  - **`↩ 취소`** → 편집 전 상태로 100% 원복 후 보기 모드.
  - **`✓ 완료`** → 그때 한 번 `saveAll`로 시트에 반영.
- 링크별 `📌 핀` · `✏️ 수정` · `🗑 삭제`, 카테고리 이름·색·삭제, `＋ 링크`, `＋ 소그룹`,
  소그룹 이름 변경·삭제.

## 북마크 HTML 가져오기

브라우저에서 내보낸 북마크 파일을 넣으면 **폴더 구조를 그대로** 살립니다.

```
북마크바 ▸ 업무 ▸ 수업 준비 ▸ 자료 링크
        └ 최상위 폴더(업무) = 카테고리, 그 아래(수업 준비) = 소그룹
```

중복 URL은 건너뛰고, `javascript:` 같은 위험한 스킴은 저장하지 않습니다.

## 설치 (약 3분)

1. Google Drive에서 새 스프레드시트를 만들고 이름을 정합니다(예: `[비공개] 나만의 북마크 포털`).
2. 그 시트에서 **확장 프로그램 → Apps Script**를 열고, 기본 코드를 지운 뒤
   [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여 넣고 저장합니다.
3. **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 후 나오는 `https://script.google.com/macros/s/…/exec` 주소를 복사합니다.
4. 이 페이지를 열고 주소 입력창에 붙여 넣습니다. 끝!

연결하면 주소창이 `…/#s=<암호화된 주소>` 형태로 바뀝니다.
그 주소를 북마크바 맨 앞에 `🏠포털`로 저장해 두면, 어느 PC에서든 그 북마크만 누르면 됩니다.

> 시트의 `링크`·`설정` 탭은 Apps Script가 처음 실행될 때 자동으로 만들어집니다.
> 예전 7열 시트(그룹 열 없음)도 그대로 동작하고, `그룹` 헤더가 없으면 자동으로 채웁니다.

## 시트 구성

- `링크` — `카테고리 | 이름 | 아이콘 | URL | 설명 | 순서 | 핀고정 | 그룹`
- `설정` — `포털제목`, `테마`, `카테고리`(`업무|#3b82f6|수업 준비;행정·공문` 처럼 색과 소그룹까지),
  `메모`, `접힘`(접힌 카테고리), `접힘그룹`(접힌 소그룹)

## 주소를 잃어버리면

`#s=…` 값이 곧 열쇠입니다. 브라우저 저장소가 지워져도 그 주소만 있으면 다시 열립니다.
스프레드시트에서 **확장 프로그램 → Apps Script → 배포 → 배포 관리**에서 주소를 다시 확인할 수 있습니다.

## 보안

- 이 저장소에는 코드만 있습니다. 링크·이름·시트 ID·웹 앱 주소가 들어 있지 않습니다.
- 링크 목록은 본인 Google 계정의 비공개 시트에만 있습니다.
- 웹 앱 주소(`…/exec`)를 아는 사람은 그 시트의 링크를 읽을 수 있으니 주소는 공유하지 마세요.
- 위험한 스킴(`javascript:` 등)은 저장·실행되지 않도록 걸러냅니다.
- 링크가 비어 있는 상태로 저장 요청이 오면 시트를 지우지 않고 거부합니다(실수 방지).

## 개발 메모

- `index.html` 단일 파일(외부 라이브러리 없음). 정적 호스팅이면 어디서든 동작합니다.
- 읽기는 JSONP(`?callback=`), 쓰기는 `text/plain` POST(프리플라이트 없음) → 안 되면 숨은 폼 POST → JSONP GET 순으로 시도합니다.
- 저장은 `saveAll`로 화면 상태 전체(카테고리 순서·색·소그룹·접힘 + 링크 순서·그룹)를 한 번에 덮어씁니다.
- 드래그는 Pointer Events 기반 직접 구현(HTML5 DnD 미사용) — 마우스·터치·펜에서 동일하게 동작하고,
  앵커 기본 드래그와 충돌하지 않습니다.
- `?demo=1` 로 예시 데이터 화면을 볼 수 있습니다.
- 이 저장소는 GitHub Pages( `gh-pages` 브랜치 )로 게시됩니다. 내용을 고칠 때는 `main`과 `gh-pages` 두 브랜치를 같이 갱신하세요.
- 백엔드 v2.0.0부터 `그룹` 열과 접힘 설정을 지원합니다. v1.1.0 백엔드에 연결하면
  소그룹은 브라우저 캐시에만 보관되고 화면 아래에 안내가 표시됩니다.
