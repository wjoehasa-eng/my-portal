# 나만의 북마크 포털 (my-portal)

북마크를 **한 화면에 카테고리 → 폴더 → 하위 폴더 → 링크 순서로 펼쳐 보는** 1장짜리 포털 페이지입니다.
브라우저 북마크의 **폴더 층위를 그대로** 살려 가져오고, 겹치는 구글 문서 아이콘은 **제목에 맞춰 자동으로 그려** 구별합니다.
링크 데이터는 이 저장소에 없습니다. **사용자 본인의 비공개 Google Sheets**에만 저장되고,
Apps Script 웹 앱을 통해 읽고 씁니다. 그래서 공용 PC에서도, 다른 기기에서도,
페이지 주소 한 줄만 있으면 로그인한 브라우저 어디서든 같은 화면이 열립니다.

```
브라우저 (이 페이지)  ──JSONP / POST──▶  Apps Script 웹앱  ──▶  비공개 Google Sheets
```

## 화면

- **첫 화면 = 아이콘 타일 그리드** — 웨일 새 탭처럼 흰 라운드 카드 안에 **연회색 둥근 아이콘 박스 + 이름 한 줄**로 된
  타일이 깔립니다. 아이콘은 그 사이트의 실제 **파비콘**을 먼저 보여주고, 파비콘이 없거나 막히면
  **이름·도메인 키워드로 고른 아이콘**(캘린더 📅, 메일 ✉️, 학교·나이스 🏫, 에듀파인 📋, 은행·카드 💳 등)이
  처음부터 자리에 깔려 있어 빈 칸이 생기지 않습니다(사용자가 고른 이모지는 그대로).
- **알약형 탭** — 카드 위쪽 `전체 · 📌 즐겨찾기 · ⚡ 단독 페이지 · 카테고리…` 탭으로 한 카테고리만 골라 봅니다
  (같은 탭을 다시 누르면 전체로).
- **🎨 카테고리 안 공간(구역) 나누기 (v3.4.0 · v3.5.0에서 내용물 크기로)** — 한 카테고리 안에서도 **폴더(소그룹)마다 파스텔 배경 + 그 색 테두리**로 감싸
  구역이 한눈에 나뉘어 보입니다(기본·연파랑·민트·연보라·살구·연노랑·로즈·세이지·하늘 9가지). 폴더 머리의 **색 점**을 누르거나
  폴더를 **오른쪽 버튼 → `🎨 공간 색상 바꾸기`** 로 한 번에 바꾸고, 같은 메뉴에서 **구역 이름(제목) 숨기기**도 됩니다.
  카테고리 빈 곳 우클릭 → **`🎨 새 구역(색상 박스) 만들기`** 로 **이름 없는 색 박스**를 바로 만들 수 있고
  (편집 모드 `🎨 구역` 단추, `＋ 소그룹`에서 이름을 비우고 확인해도 같은 결과), 폴더처럼 타일을 끌어다 넣으면 됩니다.
  **색 박스는 이제 가로로 늘어나지 않고 안에 든 아이콘 수만큼만 넓어집니다(v3.5.0)** — 한 줄에 여러 구역이 나란히 놓이고,
  화면 폭을 넘으면 자연스럽게 줄바꿈되며 최대 100%까지만 커집니다. 1~2개짜리 작은 구역도 딱 그 크기만큼 색이 잡힙니다.
  배경·테두리는 `--panel`·`--line`과 섞어 만들어 **다크 모드에서도 은은하게** 어울립니다.
  폴더 색은 시트 카테고리 설정의 예약 이름 `__colors` 한 행으로 저장되어 **Code.gs 2.1.0 수정 없이**
  모든 기기에서 같은 화면이 열립니다. 폴더 이름 변경·이동·삭제 시 색도 함께 따라갑니다.
- **🗂 탭 순서·숨기기·시작 탭 (v3.3.4)** — 상단 탭을 **끌어서** 좌우 순서를 바꾸고(탭 사이에 세로 삽입선),
  탭을 **오른쪽 버튼 → `👁 이 탭 숨기기`** 로 감출 수 있습니다. 탭 바 오른쪽 끝의
  **`⚙ 탭 관리`** 를 열면 모든 탭의 **표시/숨김 체크 + ↑↓ 순서**를 한 화면에서 바꾸고 바로 되살릴 수 있습니다
  (숨긴 탭이 있으면 `👁 N` 단추가 함께 뜹니다). 탭은 최소 하나가 남고, 보던 탭을 숨기면 남은 첫 탭으로
  자동 전환됩니다. 탭 바는 줄바꿈되어 **오른쪽으로 밀려 사라지는 탭이 없습니다**.
  **시작 탭**은 기본이 `📌 즐겨찾기`이고(`⚙ 탭 관리 → 시작 탭`에서 다른 탭으로 바꿀 수 있음),
  즐겨찾기가 하나도 없어도 즐겨찾기 탭은 열립니다. 순서·숨김은 `localStorage`에 즉시, 시트에는 카테고리 설정의 예약 이름 `__tabs`로 함께
  저장됩니다(Code.gs 2.1.0 그대로).
- **⚡ 단독 페이지** — 카테고리에 묶이지 않는 링크는 카테고리 박스 없이 카드 **맨 위 타일 줄**에 바로 놓입니다
  (제목도 폴더 감싸기도 없이 클릭 한 번에 열림). 단독 타일도 우클릭·편집·드래그·📌 고정이 그대로 됩니다.
  **단독 페이지 영역에도 폴더를 만들 수 있습니다** — 그 영역의 빈 곳에서 우클릭 → `📁 새 폴더 만들기`,
  편집 모드에서는 `＋ 폴더` 단추. 단독 타일을 폴더 안으로 끌어넣거나 폴더 밖으로 빼면 되고,
  폴더 안에 하위 폴더(깊이 제한 없음)·접기/펼치기·이름 바꾸기·삭제가 카테고리 안 폴더와 똑같이 동작합니다.
  빈 폴더도 그대로 남아 있어 나중에 타일을 끌어넣거나 `＋`로 링크를 넣을 수 있습니다.
- **📌 즐겨찾기 (타일·폴더·카테고리 · 색 박스 구역 v3.5.0 · 고정 칸 안 구역 v3.5.1 · 같은 주소 구분 v3.5.2 · 제목 줄 우클릭 v3.5.3 · 편집해도 유지 v3.7.0)** — 타일 하나뿐 아니라 **폴더와 카테고리 통째로** 즐겨찾기에 고정합니다.
  폴더 머리·카테고리 머리의 `📌`(편집 모드) 또는 우클릭 메뉴 `📌 이 폴더 즐겨찾기`로 고정하고,
  `📌 즐겨찾기` 탭에서는 고정된 타일, 고정된 폴더(안의 링크·하위 폴더가 그대로 펼쳐지고 접기/`↗ 모두 열기` 동작),
  카테고리 전체가 한 목록에 모입니다. 그 목록 안에서 **끌어서 순서를 바꾸면** 그대로 저장됩니다
  (로컬 캐시 + 시트 설정, 열 추가 없음).
  즐겨찾기 탭에서도 **파스텔 색 박스(구역)** 를 만들어 고정된 타일을 묶을 수 있습니다 —
  편집 모드의 `🎨`/`＋ 구역(색상 박스)` 단추나 즐겨찾기 탭 빈 곳 우클릭 → `🎨 새 구역(색상 박스) 만들기`로 만들고,
  타일·폴더·카테고리를 **구역 안으로 끌어넣거나 밖으로 끌어 빼고**, 구역 머리의 **색 점**·우클릭으로 색을 바꾸고
  이름을 붙이거나 숨기고, 구역 머리를 끌어 **구역 순서**를 바꿉니다. 구역 목록은 `__fzones` 예약 행으로 저장됩니다.
  **고정된 `부장`·`26_학년 업무` 같은 카테고리 칸 안에서도(v3.5.1)** 그 카테고리의 색 박스를 바로 만들고 정리합니다 —
  칸 안 빈 곳·머리 우클릭 → `🎨 이 칸 안에 새 구역(색상 박스) 만들기`(폴더 안이면 `🎨 이 폴더 안에 새 구역`),
  편집 모드에서는 칸 머리의 `🎨`·`＋`와 칸 아래 `🎨 구역(색상 박스)` 단추. 칸 안 타일을 구역 사이로 끌어넣고 빼면
  **그 카테고리 자체의 구조가 바뀌므로** 카테고리 탭·`전체` 화면에도 그대로 반영됩니다(즐겨찾기 전용 `__fzones`와 별개).
  고정된 폴더 칸 안에서도 같은 방식으로 하위 구역을 만들고 타일을 옮깁니다.
  **즐겨찾기 섹션의 제목 글자(`📌 즐겨찾기`) 위에서 오른쪽 버튼을 눌러도(v3.5.3)** 그 즐겨찾기 자신의 메뉴
  (`🎨 새 구역(색상 박스) 만들기 · 즐겨찾기 맨 위`)가 뜹니다 — 예전에는 제목 줄이 빈 카테고리(단독 페이지) 메뉴로
  잡혀서, 거기서 만든 구역이 즐겨찾기가 아니라 **단독 페이지 쪽에 생겨 보이지 않았습니다.**
  또 고정된 **폴더** 칸 안에서도 편집 모드에 칸 머리 `🎨`·`＋` 와 칸 아래 `🎨 구역(색상 박스)` 단추가 생겼고,
  오른쪽 버튼 → `🎨 구역 색 바꾸기` 팔레트가 열리자마자 닫히던 문제도 고쳤습니다(v3.5.3).
  **같은 주소(URL)를 쓰는 링크를 여러 개 만들어 둔 경우(v3.5.2)** 에도 각각 따로 고정되고 맨 위로 끌어 옮길 수 있습니다 —
  순서 목록의 링크 토큰에 같은 주소 중 몇 번째인지 `l:<지문>_1` 처럼 순번을 붙여 구분하고,
  예전에 저장해 둔 `l:<지문>` 토큰은 **고정된 링크를 먼저** 찾도록 바꿔서, 저장된 순서를 그대로 이어받습니다(구역 `__fzones` 토큰도 함께 옮겨집니다).
  **편집해도 즐겨찾기·위치가 그대로(v3.7.0)** — 즐겨찾기한 타일의 **아이콘·이름·주소·설명·폴더**를 고쳐도
  `pin` 상태와 순서, 색 박스 안의 자리가 그대로 남습니다. 토큰은 주소 지문으로 만들어지는데, 편집으로 주소가 바뀌면
  바뀐 토큰으로 순서 목록·구역을 **한 번에 옮겨 적습니다**(같은 주소를 쓰는 링크의 `_1` 순번이 밀리는 경우도 포함).
  그래서 주소를 `#s=` 자동연결 주소로 바꿔도 즐겨찾기에서 빠지지 않고, 다시 고정할 필요가 없습니다.
- **내 앱 타일은 폰 아이콘 그대로 (v3.7.0)** — `wjoehasa-eng.github.io/<저장소>/…` 링크는 그 앱 매니페스트의
  실제 PWA 아이콘(`icon-192.png` 등, 폰 홈 화면에 깔린 그림)을 타일에 씁니다. 저장소별 경로를 직접 확인해 두어
  추가 요청 없이 바로 뜨고, 파일이 없거나 못 불러오면 지금처럼 파비콘·이모지로 돌아갑니다.
  편집 창에서 **직접 고른 이모지·이미지 아이콘**은 그대로 존중합니다.
- **접기/펼치기** — 카테고리·폴더마다 누가 봐도 버튼인 `▾ / ▸`. 누르면 타일 그리드가 바로 접히고,
  상단 **`모두 접기 / 모두 펼치기`** 로 한 번에 정리할 수 있습니다. 접힌 상태는 `localStorage`와
  시트 `설정` 탭에 즉시 저장되어 새로고침·다른 기기에서도 유지됩니다.
- **탭별 접힘 분리** — `전체` 탭에서 접어 둔 카테고리는 그대로 두고, 그 카테고리 **탭 안에서는 항상 펼쳐진 채로**
  열립니다. 탭 안에서 폴더를 접거나 펴도 `전체` 화면의 접힘 상태에는 영향을 주지 않습니다.
- **폴더 속 폴더 (N단계)** — 폴더 안에 또 폴더가 들어갑니다(깊이 제한 없음). 각 폴더는 자기 타일 그리드와
  접기 버튼을 따로 가지고, 왼쪽 세로선으로 층위가 보입니다.
- **제목 맞춤 아이콘 (자동)** — 제목을 교무·업무 키워드(수업일지/학급일지/출결/시간표/회의록/가정통신문/품의·결재/
  평가/안전/급식 …)로 읽어 **색과 심볼이 다른 SVG 아이콘**을 그 자리에서 만듭니다. 그래서 같은 구글 시트라도
  `수업일지`와 `학급일지`가 확실히 구별됩니다. 키워드가 없는 문서는 제목 해시 색 + 첫 글자 아이콘,
  네이버·유튜브·깃허브 같은 브랜드 사이트는 원래 파비콘을 그대로 씁니다(맞춤 아이콘에는 원 사이트 파비콘이
  오른쪽 아래 작은 배지로 함께 표시).
- **빠른 검색** — `/`로 검색창 포커스, 이름·카테고리·설명으로 실시간 필터, `Enter`로 첫 결과 열기,
  `Esc`로 검색 초기화(열린 메뉴·창도 `Esc`로 닫힘).
- **폴더별 `↗`** — 카테고리·소그룹 머리글의 `↗`로 그 안의 링크를 새 탭에서 한 번에 엽니다
  (5개를 넘으면 한 번 확인, 팝업 차단 시 안내).
- **우클릭 메뉴** — 카테고리·폴더·빈 곳 어디서나 **`📁 새 폴더 만들기`**(그 자리 바로 아래 하위 폴더),
  링크에서는 **`📁 새 폴더 만들어 이동`**, 폴더에서는 `이 폴더에 링크 추가`. 그 밖에 링크: 열기·주소 복사·수정·
  다른 폴더로 이동·고정·삭제, 카테고리/폴더: 모두 열기·이름 바꾸기·접기·삭제. 화면 밖으로 나가지 않게 위치를 자동 보정합니다.
- **이름 바로 바꾸기** — 카테고리·소그룹 이름을 **두 번 누르면** 그 자리에서 입력창이 열립니다
  (`Enter` 저장 / `Esc` 취소). 관련 링크의 카테고리·소그룹도 함께 바뀝니다.
- **반쪽 화면 최적화** — 600·683·768px에서도 머리글 버튼과 카드 글자가 겹치거나 잘리지 않습니다.
- **즉시 표시(SWR)** — `#s=` 연결 주소별로 마지막 화면을 캐시해 **0ms에 먼저 그리고**,
  뒤에서 시트의 최신 내용을 조용히 받아 바뀐 부분만 다시 그립니다.

## 배치 (편집 모드 없이, 첫 화면에서)

- **이모지 팔레트** — 링크 추가/수정 창에서 250여 개 이모지를 **업무·학교 / 문서·일정 / 금융·투자 /
  도구·AI / 생활·취미 / 기호·색상** 칩으로 좁혀 보고, 좁은 스크롤 그리드에서 한 번 눌러 적용합니다.
- **내 아이콘 이미지** — 링크 추가/수정 창에서 이모지 대신 **이미지**를 쓸 수 있습니다.
  이미지를 복사·캡처해 두고 **Ctrl+V**(붙여넣기), **🖼 파일** 선택, **이미지 주소(URL)** 입력 — 세 가지 다 됩니다.
  파일·붙여넣기 이미지는 **96×96px로 줄여 짧은 data URL**(9,000자 이내)로 `아이콘` 칸에 저장하고,
  타일에는 그 이미지가 가장 먼저 보이며(파비콘·이모지보다 우선) 불러오지 못하면 키워드 이모지로 돌아갑니다.
  `↺ 자동 아이콘으로 되돌리기` 버튼으로 언제든 원래대로 되돌립니다.
- **링크**를 끌어 같은/다른 카테고리·**폴더(어느 깊이든)** 로 이동 — 타일의 **좌/우에 세로 `|` 삽입선**과 `↕ 순서 이동` 표시.
  붙은 타일의 왼쪽 절반에 놓으면 그 앞, 오른쪽 절반에 놓으면 그 뒤로 들어가고, 줄이 바뀌어도
  읽는 순서(윗줄 → 아랫줄)대로 자리를 잡습니다.
- **카테고리 머리글(⠿ 또는 머리글 전체)** 을 끌어 카테고리 순서 변경 — 카드 좌/우 가장자리는 `|`,
  머리글의 위/아래는 `―` 삽입선으로 정확히 표시합니다.
- **카테고리 → 다른 카테고리 본문**으로 끌면 `📁 “B” 안의 소그룹으로 넣기` 안내와 함께
  그 카테고리의 소그룹으로 바뀌고, 안의 링크가 통째로 따라갑니다.
- **소그룹 머리글**을 끌어 다른 카테고리로 이동하거나 같은 카테고리 안에서 순서 변경.
- **소그룹을 카테고리 바깥**으로 끌면 `⬆ 독립 카테고리로 꺼내기` 존이 떠서 카테고리로 승격됩니다.
- **링크를 카테고리 밖으로** 끌면 단독 페이지가 됩니다 — 카드 사이 빈 곳이나 단독 카드 위,
  또는 화면 아래 `⬆ 카테고리 밖 단독 페이지로 빼기` 존에 놓으면 `cat: ''` 로 빠집니다.
  반대로 단독 카드를 아무 카테고리·소그룹 위로 끌면 그 안으로 들어갑니다.
- 단독 카드를 카테고리 카드 사이로 끌면 그 자리(순서)에 그대로 놓입니다.
- 드래그 중에는 **8px 굵은 삽입선 + 글로우**, 놓일 대상 하이라이트, 무엇이 되는지 플로팅 배지,
  접힌 구역 위에 머물면 자동으로 펼쳐집니다. 모든 구조 변경은 `↩ 되돌리기` 토스트로 되돌릴 수 있습니다.
- 터치 기기에서는 **길게 눌러(0.23초) 끌기**, 마우스는 바로 끌기.

## ✏️ 편집 모드 (삭제·수정은 여기서만)

- `✏️ 편집`을 누르는 순간 **현재 상태 전체를 스냅샷**으로 잡습니다.
- 편집 중에는 내용을 시트에 쓰지 않고 로컬에서만 바꿉니다.
  - **`↩ 취소`** → 편집 전 상태로 원복 후 보기 모드.
  - **`✓ 완료`** → 그때 한 번 `saveAll`로 시트에 반영.
- 링크별 `📌 핀` · `✏️ 수정` · `🗑 삭제`, 카테고리 이름·색·삭제, `＋ 링크`, `＋ 소그룹`,
  소그룹 이름 변경·삭제. 접기 상태는 편집 중에도 `setSettings`로 바로 저장됩니다.
- **카테고리 드롭다운 맨 위 `(없음 · 단독 페이지)`** 로 처음부터 단독으로 추가하거나,
  기존 링크를 단독으로 바꿀 수 있습니다. 우클릭 메뉴에도 `📤 단독 페이지로 빼기` /
  `📁 카테고리로 넣기`가 있습니다.

## 북마크 HTML 가져오기

브라우저에서 내보낸 북마크 파일을 넣으면 **폴더 구조를 그대로** 살립니다.

```
북마크바 ▸ 업무 ▸ 수업 준비 ▸ 자료 링크
        └ 최상위 폴더(업무) = 카테고리, 그 아래(수업 준비) = 소그룹
```

중복 URL은 건너뛰고, `javascript:` 같은 위험한 스킴은 저장하지 않습니다.

**🗑 기존 링크 모두 비우고 새로 채우기** — 모달 아래 이 항목을 체크하면 지금 포털·시트에 있는
링크·카테고리·빈 폴더·접힘/배치 상태를 전부 지우고, 파일 내용만으로 깔끔하게 다시 채웁니다
(기본은 꺼져 있어 실수로 지울 일이 없고, 실행 전 한 번 더 확인합니다).

## 설치 (약 3분)

1. Google Drive에서 새 스프레드시트를 만들고 이름을 정합니다(예: `[비공개] 나만의 북마크 포털`).
2. 그 시트에서 **확장 프로그램 → Apps Script**를 열고, 기본 코드를 지운 뒤
   [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여 넣고 저장합니다.
3. **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 후 나오는 `https://script.google.com/macros/s/…/exec` 주소를 복사합니다.
4. 이 페이지를 열고 주소 입력창에 붙여 넣습니다. 끝!

연결하면 주소창이 `…/#s=<암호화된 주소>` 형태로 바뀝니다.
그 주소를 북마크바 맨 앞에 `🏠포털`로 저장해 두면, 어느 PC에서든 그 북마크만 누르면 됩니다.

> 시트의 `링크`·`설정` 탭은 Apps Script가 처음 실행될 때 자동으로 만들어집니다.
> 예전 7열 시트(그룹 열 없음)도 그대로 동작하고, `그룹` 헤더가 없으면 자동으로 채웁니다.

## 📨 전송함 (폰 ↔ PC)

폰과 PC 사이에 **짧은 글·링크·사진·파일**을 카톡 “나에게 보내기”보다 짧은 손짓으로 주고받는 칸입니다.
포털 오른쪽 위 **📨** 버튼으로 열리고, 폰에서는 같은 사이트의 **`/drop/`** 앱으로 씁니다.
둘 다 같은 비공개 시트(`전송함` 탭)와 내 드라이브를 함께 봅니다.

### 한 번만: 백엔드 올리기 (2.2.0 이상)

전송함은 Apps Script 쪽 기능이 함께 있어야 동작합니다. 시트에서
**확장 프로그램 → Apps Script** 를 열고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용으로 **전부 바꿔 붙여넣기** →
**배포 → 배포 관리 → ✏️(수정) → 버전: 새 버전 → 배포** 하면 끝입니다(같은 `/exec` 주소 그대로).

**그리고 한 번 더 — 드라이브 권한 승인(파일 전송에 필요)**
전송함은 파일을 내 드라이브에 쓰기 때문에, 붙여넣기만 하고 배포만 하면
글·링크는 되지만 **파일만 「드라이브 저장 권한이 아직 승인되지 않았습니다」로 막힙니다.**
편집기 위쪽 함수 목록에서 **`authorizeDrive`**(없으면 `setup`)를 고르고 **▷ 실행** →
**권한 검토 → 계정 선택 → 고급 → 이동(안전하지 않음) → 허용** 을 한 번 해 주세요.
(이미 파일 전송이 되고 있다면 이 단계는 이미 끝난 것입니다. `?action=ping` 의 `driveOk` 가 `true` 면 정상)

앱도 이 상태를 알아채고 **파일 전송이 잠겨 있다고 먼저 알려 주며**, 실패한 파일은 목록에 남겨 두고 **다시 시도** 버튼을 띄웁니다.
올리기 전에는 전송함 패널에 “Code.gs 를 2.2.0 으로 올려 주세요” 안내가 뜹니다.

### PC (나만의 포털)

- 헤더 **📨** → 오른쪽에서 전송함이 열립니다. 새 항목이 있으면 버튼에 숫자가 붙습니다.
- 위 칸에 글·링크를 넣고 **보내기**, 또는 **Ctrl+V** — 글은 바로 보내고 **캡처 이미지는 이미지로** 보냅니다(파일 저장 없이).
  파일은 그 칸에 **끌어다 놓아도** 됩니다.
- 각 항목은 **누르면 복사**, 파일·사진은 **⬇ 저장**, 오른쪽 아래 **🗑** 로 삭제.
- **골라 지우기 (v3.7.0)** — 항목마다 **체크박스**가 있고, 목록 위 **전체 선택 · 전체 해제 · 선택 삭제(N)** 로
  한 번에 정리합니다. 체크 상태는 새로고침·20초 자동 갱신에도 풀리지 않고, 삭제는 시트 `전송함` 탭에서도
  실제로 지워집니다(`deleteDrop`). 같은 id 가 여러 줄 있으면 그 줄까지 함께 정리합니다.
- **전송 시각 (v3.7.0)** — `방금 · 10분 전` 같은 상대 시간은 그대로 두고, 그 아래에 **정확한 시각**
  (`11/27 10:08`, 다른 해는 `2025-12-31 09:05`)을 함께 보여 줍니다.
- **한 번만 저장 (v3.7.0)** — 보내기 연타·모바일 중복 터치는 보내는 동안 잠기고, 전송마다 고유 `cid` 를 붙여
  응답을 못 받아 다시 보내도 같은 건은 한 번만 기록됩니다(백엔드 2.3.0 이상에서 서버 쪽도 중복을 걸러 냅니다).
- **📱** 버튼 → 폰에서 찍을 **QR** 과 연결 링크가 나옵니다(QR은 이 브라우저 안에서만 그립니다 — 바깥 QR 서비스 호출 없음).

### 폰 (갤럭시)

- 포털의 **📱** 에서 QR을 찍거나 링크를 열면 `/drop/` 가 열리고, 한 번만 연결하면 그 뒤로는 자동입니다.
- 위에 글을 붙여넣고 **보내기**, **📋 붙여넣어 보내기**(클립보드에서 바로), **📎 파일/사진**.
- **Ctrl+V** 로 캡처 이미지를 바로 붙일 수도 있습니다 — 대기 칩에 `clipboard-YYYYMMDD-HHMMSS.png` 로 올라오고
  **보내기**(또는 Ctrl+Enter) 한 번이면 전송됩니다. 글만 붙여넣으면 예전처럼 입력칸에 그대로 들어가고,
  글과 이미지를 함께 복사했으면 글은 입력칸에, 이미지는 대기 칩에 나뉘어 들어갑니다.
- **어떤 파일이든** 됩니다 — `.gs`·`.txt`·`.json`·`.zip`·사진·PDF 등(확장자 제한 없음, 한 개 12MB까지).
  안드로이드에서 파일 종류(`file.type`)가 비어 오는 경우는 **이름으로 짐작**해 처리합니다.
- 보내지 못한 파일은 사라지지 않고 대기 목록에 남습니다 — **다시 시도** 한 번이면 다시 전송합니다.
- 아래 목록에서 **1클릭 복사**, 사진은 **🖼 보기 / ⬇ 저장**, **🗑** 삭제, 20초 자동 새로고침(끄고 켤 수 있음).
- **전송 시각**은 `방금`·`n분 전` 아래에 `11/27 10:08` 처럼 정확히 함께 적힙니다.
- 목록에서 같은 내용이 두 번 보이지 않습니다(20초 안에 중복 저장된 줄은 한 번만 표시).
- 브라우저 메뉴 → **앱 설치 / 홈 화면에 추가** 를 하면 독립 앱이 되고,
  갤럭시 **공유하기** 목록에 **내 전송함**이 생깁니다. 사진·링크에서 `공유 → 내 전송함` 한 번이면 전송됩니다.

### 파일은 어디에 저장되나

- 파일 본문은 **내 구글 드라이브 루트의 `[모봉] 전송함` 폴더**에 저장됩니다(없으면 자동 생성).
- **공유 설정을 하지 않습니다** — 내 계정에서만 열리는 비공개 파일이고, 링크를 아는 사람에게 열어 주지 않습니다.
- 한 개 **12MB**까지. 시트 `전송함` 탭에는 파일 ID만 적히고, 내려받기는 **시트에 적힌 파일만** 허용됩니다.
- 삭제하면 시트 행과 함께 드라이브 파일도 휴지통으로 갑니다.


## 북마크 HTML 가져오기 (층위 그대로)

- **북마크바 직속 링크** → **단독 페이지** (`cat: ''`)
- **1단계 폴더** (예: `26_학년 업무`, `부장`, `개인`) → **카테고리**
- **2단계 이상 폴더** (예: `개인 > 재테크 > 환율`) → **폴더 경로** `재테크/환율` (그 아래로 계속 중첩)
- 이미 들어 있던 링크는 **`이미 있는 링크 N개도 이 폴더 구조로 다시 배치`** 를 체크해 한 번에 정리할 수 있습니다
  (URL이 같으면 새로 넣지 않고 위치만 옮깁니다).

## 시트 구성

- `링크` — `카테고리 | 이름 | 아이콘 | URL | 설명 | 순서 | 핀고정 | 그룹`
  - **카테고리 칸이 비어 있는 행 = 카테고리 밖 단독 페이지** (시트에서 직접 그렇게 써도 됩니다)
- `설정` — `포털제목`, `테마`, `카테고리`(`업무|#3b82f6|수업 준비;행정·공문` 처럼 색과 소그룹까지),
  `메모`, `접힘`(접힌 카테고리), `접힘그룹`(접힌 소그룹),
  `배치`(첫 화면 최상위 순서: `c:업무` = 카테고리 카드, `s:https://주소` = 단독 카드, 줄바꿈 구분)
  - 단독 페이지 폴더 목록과 즐겨찾기 순서, **상단 탭 순서·숨김**, **폴더별 공간(구역) 색·제목 숨김**, **즐겨찾기 색 박스(구역)** 는 **시트 열을 늘리지 않고** `카테고리` 값 안에
    예약 이름 `__solo`·`__pins`·`__tabs`·`__colors`·`__fzones` 로 함께 저장됩니다(값은 base64 한 조각이라 폴더 이름에 쉼표·세미콜론이 있어도 안전).
    화면에는 카테고리로 보이지 않습니다. `__`로 시작하는 카테고리 이름은 만들 수 없습니다.
  - **폴더·카테고리 이름에 `,` `;` `|` 가 들어 있으면**(예: `행복한김선생(국어, 도덕)`) 그 이름만
    `~64~<base64>` 한 조각으로 바꿔 저장합니다. 설정 칸이 쉼표·세미콜론으로 나뉘어서, 그대로 넣으면 목록이
    쪼개져 **없는 카테고리가 생기고 폴더가 사라집니다**(v3.3.4에서 고침).
    Apps Script(`Code.gs` 2.1.0 이상)는 이 값을 글자 그대로 보관하므로 백엔드 수정은 필요 없습니다.
- `전송함` — `ID | 생성시각 | 보낸곳 | 종류 | 내용 | 파일명 | 파일크기 | 파일ID | 보관상태`
  - 종류: `text`(글) `link`(주소 한 줄) `file` `image`. 파일 본문은 드라이브에 있고 여기에는 `파일ID` 만 적힙니다.
  - 처음 전송함을 쓸 때 자동으로 만들어집니다(시트에 미리 만들 필요 없음).

## 주소를 잃어버리면

`#s=…` 값이 곧 열쇠입니다. 브라우저 저장소가 지워져도 그 주소만 있으면 다시 열립니다.
스프레드시트에서 **확장 프로그램 → Apps Script → 배포 → 배포 관리**에서 주소를 다시 확인할 수 있습니다.

## 보안

- 이 저장소에는 코드만 있습니다. 링크·이름·시트 ID·웹 앱 주소가 들어 있지 않습니다.
- 전송함의 파일은 내 드라이브의 `[모봉] 전송함` 폴더에 **비공개**로 저장되고, 공유 링크를 만들지 않습니다.
- 링크 목록은 본인 Google 계정의 비공개 시트에만 있습니다.
- 웹 앱 주소(`…/exec`)를 아는 사람은 그 시트의 링크를 읽을 수 있으니 주소는 공유하지 마세요.
- 위험한 스킴(`javascript:` 등)은 저장·실행되지 않도록 걸러냅니다.
- 링크가 비어 있는 상태로 저장 요청이 오면 시트를 지우지 않고 거부합니다(실수 방지).
